# Product intent

Help an entrepreneur move from a stated problem and local operating context to an evidence-backed, editable business plan.

- Start empty: no sample projects, default financial numbers or bundled patent examples.
- Ask the user to choose their patent source. Use fresh source responses and distinguish integrated search from external search handoffs.
- Make AI setup accessible: installed Ollama detection, browser-embedded model preparation, and session-only API credentials for named or compatible providers.
- Treat operating country, registration country, region, intended use and cross-border activities as planning constraints. Tie requirements to dated official evidence where provided; otherwise show verification tasks.
- Keep document readability, territorial patent rights and published license costs separate.
- Propose combinations and simpler alternatives with traceable evidence. User review precedes changing the business direction.
- Never manufacture financial inputs, technical performance, licensing permissions, regulatory approvals or market evidence.
- Preserve user work through local persistence and portable backups. Never export API credentials with projects.
